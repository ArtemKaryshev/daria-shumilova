# Сайт-портфолио Дарьи Александровны Шумиловой

Одностраничный сайт и админ-панель для редактирования. Сборка не нужна: это обычные HTML, CSS и JS-файлы, их можно разместить на любом бесплатном хостинге.

```
index.html            сайт
admin.html            админ-панель (адрес: ваш-сайт/admin.html)
config.js             адрес и ключ Supabase (заполнить один раз)
content/default.json  содержимое по умолчанию и резервная копия
supabase/setup.sql    скрипт настройки базы
assets/               стили, скрипты, иконка, библиотека Supabase
tests/run-tests.js    автотесты
```

Сайт работает сразу, даже без базы: он показывает содержимое из `content/default.json`. Админка без базы открывается в демо-режиме, и правки сохраняются только в браузере. Чтобы правки из админки появлялись на сайте у всех, подключите Supabase (шаг 2).

---

## Шаг 1. Опубликовать сайт на GitHub Pages (бесплатно, открывается в России без VPN)

1. Войдите на https://github.com и создайте репозиторий: **+ → New repository**, имя `daria-shumilova`, тип **Public**, без README. Нажмите **Create repository**.
2. На странице пустого репозитория нажмите ссылку **uploading an existing file**. Перетащите в окно **всё содержимое** папки `daria-portfolio` (сами файлы и папки, не саму папку). Нажмите **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, папка / (root) → Save.**
4. Через 1–2 минуты сайт откроется по адресу `https://ваш-логин.github.io/daria-shumilova/`, админка по адресу `…/daria-shumilova/admin.html`.

Чтобы поменять файл позже (например, `config.js`): откройте его в репозитории, нажмите карандаш ✏️, внесите правку и нажмите **Commit changes**. Сайт обновится сам через минуту.

Шрифты и библиотека Supabase лежат прямо в проекте, поэтому сайт не обращается к Google и зарубежным CDN.

## Шаг 2. Подключить базу Supabase для админ-панели (10 минут, бесплатно)

1. Зарегистрируйтесь на https://supabase.com → **New project**. Придумайте пароль базы (он вам больше не понадобится) и выберите регион **Central EU (Frankfurt)**.
2. Когда проект создастся, откройте **SQL Editor → New query**, вставьте весь текст из `supabase/setup.sql` и нажмите **Run**. Должно появиться `Success`.
3. Создайте свою учётную запись: **Authentication → Users → Add user → Create new user**. Введите свою почту и надёжный пароль, поставьте галочку **Auto Confirm User**.
4. Снова откройте **SQL Editor** и выполните строку, подставив свою почту:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'ваша@почта.ru'
   on conflict do nothing;
   ```
5. Запретите регистрацию посторонним: **Authentication → Sign In / Providers**, выключите **Allow new users to sign up** и сохраните.
6. Возьмите ключи: кнопка **Connect** вверху проекта (или **Project Settings → API**). Скопируйте **Project URL** и ключ **anon / publishable**.
7. Откройте `config.js` в любом текстовом редакторе и вставьте значения в кавычки:
   ```js
   SUPABASE_URL: "https://xxxxxxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJhbGciOi...",
   ```
   Ключ `anon` публичный, его можно хранить на сайте. Менять данные может только пользователь из таблицы `admins`.
8. Сохраните изменения в `config.js` на GitHub (карандаш ✏️ → Commit changes).
9. Откройте `https://ваш-сайт/admin.html`, войдите и нажмите **Сохранить**: исходное содержимое запишется в базу. Готово.

Для восстановления пароля: **Authentication → URL Configuration → Site URL**, укажите адрес сайта. Тогда ссылка «Забыли пароль?» будет вести обратно в админку.

## Как пользоваться админ-панелью

- **Достижения и грамоты**: «Добавить достижение», затем название, категория, год, организатор, описание и **скан грамоты** (кнопка «Загрузить файл»). Отметка «Главное достижение» поднимает карточку наверх, «Скрыть с сайта» делает её черновиком.
- **Главный экран**: здесь загружается ваше фото. Оно показывается в круге, лицо лучше расположить по центру.
- **Контакты**: Telegram, MAX, e-mail, ВКонтакте. Пустые поля на сайте не показываются.
- Порядок карточек и пунктов меняется стрелками ↑ ↓.
- После правок нажмите **Сохранить** (или Ctrl+S). Изменения сразу появятся на сайте.
- **Резервная копия и доступ**: скачать или загрузить `content.json`, сменить пароль. Скачанный файл можно положить в `content/default.json`, тогда сайт покажет свежую версию, даже если база временно недоступна.

- **Кадр фото**: под фото кнопка «Настроить кадр». Фото можно перетащить мышкой или пальцем и приблизить ползунком. Исходный файл не обрезается, кадр можно поменять в любой момент.
- **Блоки страницы**: порядок блоков (стрелки), скрытие, удаление (✕) и «Новый блок» со своим заголовком, текстом, пунктами и фото. Убранный стандартный блок возвращается через список «Вернуть убранный блок». Шапка с фото всегда наверху.

Фото и сканы автоматически уменьшаются до разумного размера перед загрузкой. Ограничение 10 МБ на файл.

## Проверка и тесты

Проверить локально:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000 и http://localhost:8000/admin.html

Автотесты (нужны Node.js и Playwright):

```bash
npm i -D playwright && npx playwright install chromium
node tests/run-tests.js
```

## Важно

- **Фото детей** публикуйте только с письменного согласия родителей.
- Supabase на бесплатном тарифе **ставит проект на паузу, если к нему неделю никто не обращался**. Сайт при этом продолжит работать на резервной копии `content/default.json`, но без последних правок и фото из базы. Чтобы этого избежать, заходите в админку хотя бы раз в неделю и держите резервную копию актуальной (см. выше). Снять паузу можно кнопкой **Restore** в панели Supabase.
- Проверьте, что сайт открывается с мобильного интернета в России: доступность зарубежных сервисов у разных провайдеров отличается.
